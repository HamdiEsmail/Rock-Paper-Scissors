# Rock Paper Scissors 🎮

A console-based Rock Paper Scissors game built with C++.

The game allows the player to play multiple rounds against the computer
and displays the results and final winner at the end of the game.

## 🚀 Features

- Choose between Stone, Paper, and Scissors
- Play multiple rounds
- Computer generates random choices
- Determine the winner of each round
- Track player wins
- Track computer wins
- Track draws
- Display round results
- Display final game results
- Play again option
- Input validation
- Change console color based on the round winner

- Functions
- Random Number Generation
- Console Application

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Visual Studio.
3. Build the project.
4. Run the application.
5. Choose the number of rounds and start playing.
